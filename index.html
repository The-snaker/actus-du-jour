Actus du jour

Actualisation instantanée

Les actualités sont collectées automatiquement toutes les 5 heures. Le bouton d’actualisation recharge toujours les dernières données publiées.

Pour qu’il lance une nouvelle collecte tout de suite (environ 1 minute), colle ici un jeton GitHub limité à ce seul dépôt.

  1. Sur GitHub : Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Repository access : Only select repositories, puis actus-du-jour.
  3. Permissions › Repository permissions › Actions : Read and write.
  4. Crée le jeton, copie-le et colle-le ci-dessous.

Le jeton reste dans ce navigateur et n’est envoyé qu’à GitHub. À refaire sur chaque appareil.
